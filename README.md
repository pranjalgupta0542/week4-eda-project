# Week 4: Exploratory Data Analysis and Feature Engineering

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) and Feature Engineering for Beauty & Wellness Customer Churn and Recommendation.

The project uses a simulated dataset containing 15,718 customer reviews, 1,500 users, and 300 products from 2021 to 2023.

## Objectives
- Perform Exploratory Data Analysis.
- Identify customer behaviour and market trends.
- Perform statistical analysis.
- Understand customer churn patterns.
- Apply feature engineering techniques.
- Explore customer segmentation and churn prediction.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Scikit-learn
- Graphviz

## Project Files
1. `Week4_EDA_Feature_Engineering.docx` – Complete internship report.
2. `make_eda_data.py` – Generates the simulated dataset.
3. `eda_features.py` – Performs EDA, feature engineering, clustering and churn prediction.

## Key Findings
- Sunscreen reviews increase during summer.
- Retinol product popularity increases over time.
- Sensitive-skin users give lower ratings to fragranced products.
- Negative reviews tend to be longer.
- Price has no significant relationship with ratings in the simulated dataset.
- Engineered features provide only a small improvement in churn prediction.

## Conclusion
This project demonstrates how EDA and feature engineering can help understand customer behaviour, identify trends, segment customers and analyse churn.

**Note:** All data used in this project is synthetic and does not represent actual market behaviour.
